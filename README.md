# True Crime: Streets of LA - Xbox Recompilation

### True Crime: Streets of LA PC Port made by recompiling the Original Xbox version and providing full modern PC options

This port is made using [Xbox XBE Recomp](https://github.com/TGP482/XboxXBE-Recomp) Tool

<sub><b>No game files included</b>: You need to provide your legally owned True Crime: Streets of LA European (PAL) Xbox Redump, in order for the recompilation to run. <b>Linux support is still on hold<b>: I do not have and use Linux unfortunately. Unless someone contributes to port and test it on Linux, This is Windows only for now</sub>

## Supported Versions

| Build | Disc | Role | default.xbe SHA-1 |
|---|---|---|---|
| 4156000E Europe (PAL) | Xbox DVD, En/Fr/De/Es/It, XDK 5659 | Base game, required, plays on its own | `7c665c36…6456` |
| USA (NTSC) | not checked | Not supported | – |
| Japan | not checked | Not supported | – |

Full hash: `7c665c36d4883e087d949d0b6961dd6465484456`. A full disc dump or a trimmed xiso both work, since only the `default.xbe` inside is checked.

## How To Use

1. Put your chosen redump (`.iso`) or extracted xbe with your data folder beside it (`\Data and default.xbe`) into the `\assets` folder
2. Run `build.bat` 
3. Wait until it finishes
4. Press `Y` after it says "Play Now?: (Y/N)"?
5. To find your generated build. Go To: `\out\build` and run `TrueCrimeLA.exe`
